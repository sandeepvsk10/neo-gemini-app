# Neo Gemini

A local Gemini theme inspired by ChatGPT, with an optional helper for automatic input expansion.

## Setup

1. Paste `gemini-chatgpt-theme.user.css` into Stylus and save.
2. Install `gemini-composer-sizing.user.js` in Tampermonkey and enable user scripts.
3. Open Gemini. Disable the extensions’ style or script to undo the customization.

See [changes.md](changes.md) for detailed notes and change history.
